# Rice Setup Installer
--- 
It's a GTK GUI made in C++ for make easy setting up and ricing on your favorite distro linux

--- 
## How To Install 

**ARCH**
- Download the file on the release section and execute this:
`sudo pacman -U file-name.pkg.tar.zst`

**UNIVERSAL (CURL)**
`curl -fsSL https://raw.githubusercontent.com/Raph-Rodrigues/Rice-Setup-Installer/main/install.sh | bash`
